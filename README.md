# boylanda.github.io

Academic homepage for David Boylan, Lecturer in Philosophy at the University of Glasgow.

Migrated from [david-h-boylan.weebly.com](https://david-h-boylan.weebly.com/). Plain static HTML/CSS, served via GitHub Pages.

## Structure

- `index.html` — home / bio
- `research.html` — publications
- `teaching.html` — courses and teaching materials
- `contact.html` — contact details
- `assets/` — stylesheet and profile photo
- `files/` — self-hosted PDFs (CV, drafts, syllabi previously hosted on Weebly)

## Updating

Edit the relevant `.html` file directly and push to `main` — GitHub Pages redeploys automatically within a minute or two.
